# Networking and DNS

## Overview

This part of the lab focuses on basic Linux networking and DNS troubleshooting.

The main tools used were:

- ip
- ping
- nslookup
- dig
- ss

## What I Learned
The main lesson from this exercise is that network troubleshooting should be performed in layers.
A failed connection does not automatically mean that the entire network is down.

The problem could be:
- An interface problem
- A routing problem
- A DNS problem
- A service problem
- A port problem
- A firewall problem
